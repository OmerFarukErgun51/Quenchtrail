# ⚒️ Demir Usta

Android için 2D pixel art mobil **demircilik RPG** oyunu. Oyuncu bir usta demirci; silah döver, satar ve kendi dövdüğü silahlarla canavar avına çıkar.

> **Durum:** Tasarım / beyin fırtınası aşaması. Henüz kod yok. Oyunun kalbi olan **demircilik sistemi** detaylı tasarlanıyor; canavar avı ve maden daha sade/ikincil kalacak.

## 📂 İçerik

- [`docs/TASARIM-KARARLARI.md`](docs/TASARIM-KARARLARI.md) — **buradan başla.** Beyin fırtınasında alınan tüm kararlar, açık sorular ve sonraya bırakılan fikirler.
- [`docs/GDD.md`](docs/GDD.md) — orijinal tam oyun tasarım belgesi (Game Design Document).
- [`docs/mockups/forge-animated.html`](docs/mockups/forge-animated.html) — dövme akışının animasyonlu taslağı (tarayıcıda aç: potaya at → erit → kalıba dök → döv → soğut → kılıç).
- `docs/references/` — konsept/mockup görselleri.

## 🎯 Özet

- **Tür:** Casual crafting RPG + canavar avı (Stardew/Forager havası, sevimli pixel art)
- **Platform:** Android (Google Play)
- **Motor:** Godot 4 (henüz kesinleşmedi — GDD'de Unity 2D yazıyor)
- **Çekirdek döngü:** maden topla → silah döv → canavar avla → loot → sat → geliştir → tekrar

## ▶️ Devam etmek için

Diğer bilgisayarda bu repoyu klonla, `docs/TASARIM-KARARLARI.md`'yi oku, oradan kaldığın yerden devam et. Demircilik akışı, dükkân, gün döngüsü ve ilerleme tasarımı oturdu. Sırada **dövme mockup'ının yeni akışa göre güncellenmesi** ve **ekonomi dengesi** (fiyatlar, malzeme maliyetleri) var.
